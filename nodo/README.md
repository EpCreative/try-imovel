# NØDO Explorar (prévia)

Versão estática do NØDO Explorar, publicada pelo GitHub Pages. O código-fonte do app fica no branch principal deste repositório, em `explorar/`; este branch (`gh-pages`) guarda só o build.

Catálogo de demonstração: nomes, preços e imagens são provisórios. Os links para a loja mostram um aviso até a loja NØDO ter endereço público.
